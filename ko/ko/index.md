# Tinkomi 한국어 — 무료 도구로 배우는 실전 데이터 활용

설치 부담은 줄이고, 브라우저에서 직접 따라 해보는 실용적인 소프트웨어 안내입니다. 데이터 형식과 무료 도구 사용법을 쉬운 예제로 익혀 보세요.

## 첫 실습

## 무료 도구

**DataStudio Lite**는 JSON·CSV 변환, JSON 정리, Markdown 표 변환을 제공하는 브라우저 도구입니다. 무료 버전에서 사용할 수 있는 기능을 확인하고 예제 데이터로 체험해 보세요.
